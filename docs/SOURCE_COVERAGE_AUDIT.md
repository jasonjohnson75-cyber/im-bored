# I'm Bored Source Coverage Audit

Launch center: 46637. Target radius: 30 miles.

## Audit dimensions
- Geographic balance: South Bend, Mishawaka, Notre Dame/Granger, Elkhart/Goshen, Niles/Buchanan and nearby communities.
- Audience balance: family, adult, student, senior and all-ages inventory without favoring one group.
- Category balance: music/nightlife, arts/culture, sports, family, food/markets, outdoors, community/civic, learning, seasonal/festival.
- Freshness: active sources refreshed on an appropriate cadence.
- Provenance: every event retains an organizer/source URL.
- Quality: valid title/date, stable source event ID, location when supplied, cancellation handling, duplicate control.

## Promotion policy
A source may be engineered and dry-run before promotion. Production promotion requires the source-quality gate. Aggregators may improve recall but must not replace direct organizer sources when both are available. Duplicate events should retain provenance to all contributing sources while presenting one canonical event.

## Current engineering waves
Wave 1 proves API and structured-calendar ingestion. Wave 2 expands civic and downtown calendars. Later waves expand universities, museums, venues, libraries, parks, markets, festivals, chambers, tourism and long-tail community calendars until coverage, not an arbitrary count, is sufficient.
